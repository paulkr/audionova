# The local application

**3 August 2026.** Upload, measure, plan, render, compare, refine — working end
to end in a browser.

```sh
./.venv/bin/uvicorn backend.api.server:app --port 8787   # the audio API
npm run dev                                              # the UI
```

## The shape

```
browser ──file bytes──▶ FastAPI :8787 ──▶ measure ──▶ plan ──▶ engine ──▶ gate
   │                         │                                              │
   └──JSON, audio streams────┴──────────────────────────────────────────────┘
```

**Audio never traverses Next.js.** Server Actions cap request bodies at 1 MB and
a three-minute 24-bit WAV is about 50 MB. Adding a `proxy.ts` would get a 10 MB
default that *silently truncates* larger bodies with only a console warning — a
data-corruption bug that returns success. A CI gate asserts this stays true.

## What the studio shows

- **Measurements before and after**, with the delta on each. Loudness, true peak,
  loudness range, crest, peak-to-loudness, HF rolloff.
- **A third-octave spectrum**, both curves normalised to their own midrange so
  the comparison is of *shape* rather than level.
- **Every node with every parameter and its units**, plus the sentence the
  planner wrote about why that node exists. An engineer decides whether to trust
  this by reading it.
- **What was deliberately left alone**, when the deterministic planner is used.
- **A loudness-matched, gapless A/B.** Both are load-bearing: louder wins a blind
  comparison regardless of quality, and a gap lets memory fill in the difference.
  The two elements share a playhead so switching keeps position.
- **Refinement buttons** from the closed intent vocabulary, each a patch against
  the accepted chain rather than a regeneration.

## Seams left open, deliberately

Each is marked in `backend/api/server.py` where it belongs:

| now | production |
|---|---|
| temp directory keyed by opaque id | S3 presigned multipart, direct from browser |
| synchronous render | Temporal workflow keyed on recipe hash |
| our own WAV reader only | sandboxed FFmpeg, `--network none` |
| in-memory project dict | Postgres with RLS |
| none | auth, tenancy, quota, billing |

Only WAV is accepted. Anything else is rejected rather than guessed at, because
decoding attacker-controlled bytes is what the ingest sandbox exists for and it
is not built.
